ROSE GOLD website
=================

Files:
- index.html: website structure
- style.css: responsive rose-gold styling
- script.js: mobile menu and current year
- rose-gold-logo.png: your supplied brand logo

Preview:
Open index.html in Chrome or another browser.

Before publishing:
1. Replace the Instagram homepage link in index.html with your actual business Instagram profile URL.
2. Add your real product photos, names and prices.
3. Upload this folder to a static hosting service (for example GitHub Pages, Netlify or Cloudflare Pages) to get a public website URL.

Suggested URL / domain:
- rosegoldbeauty.in
- rosegoldmakeup.in
- shoprosegold.in

These are suggestions only; availability has not been checked or registered.
